# Using gapi

Operator-facing prose about the kernel: what it supervises, how it is
brought up, and what it guarantees.

This is the hand-written half of the site. Where a page here states a
value the code defines - a default, a port, a timeout - it names the key
rather than transcribing the number, so that the generated
[configuration reference](../reference/configuration/) stays the single
place that value is published.
