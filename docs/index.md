# GAPI Documentation

Welcome to the **GoPPydae Agent Programming Interface** (GAPI) documentation.

## Core Concepts

- **Supervisor**: The kernel that manages agent lifecycles.
- **Agents**: Standalone units of logic (Go, Python).
- **Event Bus**: The nervous system connecting agents.
